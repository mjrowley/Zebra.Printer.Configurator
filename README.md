# Zebra.Printer.Configurator
An Android application that utilises NFC pairing to connect a WiFi enabled printer to a local network and configure printer settings

This application is primarily meant for the Zebra ZD421, but will work with any NFC pairing enabled and WiFi enabled Zebra printer model. For example the ZQ630 Plus.
https://www.zebra.com/ap/en/support-downloads/printers/desktop/zd421.html

The key to interacting with Zebra printers is the Zebra Link-OS SDK. Documentation is available online here.
https://techdocs.zebra.com/link-os/

This application is written in .NET 10 MAUI (Multi-platform App UI) and is a hybrid Blazor application.
https://dotnet.microsoft.com/en-us/apps/maui
https://learn.microsoft.com/en-us/aspnet/core/blazor/hybrid/tutorials/maui?view=aspnetcore-10.0
